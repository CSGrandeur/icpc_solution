### `Critical Strike`

> difficulty: 4

[QOJ 17764](https://qoj.ac/contest/3588/problem/17764)

0-1 背包。先按 $v$ 排序，这样在考虑第 $j$ 个装备时，该装备是已考虑装备里倍率最高的。若购买第 $j$ 个装备，期望倍率为：$j$ 不生效概率 $\times$ 之前的期望 $+$ $j$ 生效概率 $\times$ $j$ 的倍率。

```cpp
/*
L. Critical Strike
0-1 背包
先按 v 排序，这样在考虑第 j 个装备时，该装备就是已考虑的装备里倍率最高的
如果购买第 j 个装备，期望倍率就是 j不生效概率*之前的期望 + j生效概率*j的倍率
*/
#include<stdio.h>
#include<stdlib.h>
#include<string.h>
#include<algorithm>
const int maxn = 3e3 + 10;
double dp[maxn][maxn];
struct Node {
    int w, p, v;
    bool operator<(const Node &that) {
        return v < that.v;
    }
};
Node nd[maxn];
int main() {
    int t, n, m;
    for(scanf("%d", &t); t --; ) {
        memset(dp, 0, sizeof(dp));
        scanf("%d%d", &n, &m);
        for(int i = 1; i <= n; i ++) {
            scanf("%d%d%d", &nd[i].p, &nd[i].v, &nd[i].w);
        }
        std::sort(nd + 1, nd + n + 1);
        for(int i = 1; i <= n; i ++) {
            for(int j = 0; j <= m; j ++) {
                dp[i][j] = dp[i - 1][j];
                if(j >= nd[i].w) {
                    dp[i][j] = std::max(dp[i][j], 
                    (100 - nd[i].p) / 100.0 * dp[i - 1][j - nd[i].w] + nd[i].p / 100.0 * nd[i].v);
                }
            }
        }
        printf("%.12f\n", dp[n][m]);
    }
    return 0;
}
```
