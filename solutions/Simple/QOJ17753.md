### `Greetings from Prof. Chen`

> difficulty: 2

[QOJ 17753](https://qoj.ac/contest/3588/problem/17753)

考虑不等式 `left <= x_0 + x_1 + ... + x_k <= right`：`left` 是 `'a' * k`，`right` 是 `'z' * k`，一定能得到 `left` 到 `right` 的连续值。`n / 'a'` 向下取整后是 `left` 不超过 `n` 的最大 `k`，此时若 `right >= n` 即可构造。只考虑该 `k` 即可：`k` 更小时 `right` 只会更小，`k` 更大时 `left` 会超过 `n`。

```cpp
/*
A. Greetings from Prof. Chen
考虑不等式
left <= x_0 + x_1 + ... + x_k <= right
left 是 'a' * k， right 是 'z' * k，一定能得到 left ~ right 的连续值
n / 'a' 向下取整后，是 left 不超过 n 的 最大的 k，此时 right 不小于 n 就可以构造
只考虑这一个情况就够了，因为 k 更小的话，right只会更小，k更大的话，left就会超过n
*/
#include<stdio.h>
#include<stdlib.h>
int main() {
    int t, n;
    for(scanf("%d", &t); t --; ) {
        scanf("%d", &n);
        int cnt = n / 'a';
        int high = cnt * 'z';
        if(high >= n) {
            printf("Yes\n");
            int base = n % 'a' / cnt;
            int num = n % 'a' % cnt;
            int check = 0;
            for(int i = 0; i < cnt; i ++) {
                printf("%c", 'a' + base + (i < num ? 1 : 0));
                // check += 'a' + base + (i < num ? 1 : 0);
            }
            printf("\n");
            // printf("%d %d\n", n, check);
        } else {
            printf("No\n");
        }
    }
    return 0;
}
```
